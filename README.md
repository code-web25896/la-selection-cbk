# La Sélection CBK

Site vitrine et catalogue CBK avec serveur Node.js.

## Développement local

```sh
npm ci
npm start
```

Le site écoute par défaut sur `http://127.0.0.1:3000`.

## Déploiement

Consulter [DEPLOIEMENT-HOSTINGER.md](DEPLOIEMENT-HOSTINGER.md) pour la configuration Hostinger.

Les données d’exécution, identifiants, commandes et comptes locaux restent dans `.local-data/` et ne doivent pas être publiés.
